## Inference of the Breeding Sex Ratio and Demographic History 

In this directory, we provide the scripts used to develop and test our methods for inferring the breeding sex ratio (BSR) and demographic history from X-linked and autosomal patterns of variation. Here, we describe the general process we take to first simulate genomic data to input into our inference methods, then, using these patterns of variation, infer the BSR and population size change using two novel approaches and one previously developed method. 


Many of our scripts were written for the purpose of running in parallel using the University of Wisconsin-Madison's Center for High Throughput Computing (CHTC), so the output will be a base unit to be combined later. 

### Simulating X-linked and Autosomal Patterns of Variation

Our simulation framework adapts the process described in the [BSR_simulations repository](https://github.com/PayseurLabUWMadison/BSR_simulations), using `msprime`, a coalescent simulator that enables us to specify any demographic model and BSR to output patterns of variation on X-linked and autosomal loci. Using the script `abc_dadi_combined_obs_sims.py`, we tailor our simulations so each replicate produces a frequency spectrum (FS) object summarizing the allele frequencies of variants on each chromosome class along with a table of summary statistics including nucleotide diversity and measures of linkage disequilibrium. These output files serve as the inputs for each of the methods of inference in their respective sub-directories. We configured this process such that the same simulated data is summarized by the FS and statistic table, allowing us to directly compare the performance of each method. In the following sections, we will outline the process of inferring the BSR and demographic history for each approach. 

### Inference using Approximate Bayesian Computation with Random Forest (ABC-RF)

To infer the BSR and demographic history using ABC-RF, we start by constructing a reference table of 1 million simulations. Using `abc_sims_v5.py`, we draw parameter values from a uniform prior distribution with upper and lower bounds determined by the scenario of interest. Using these parameter values, we simulate X-linked and autosomal variation by adjusting the effective population size for each chromosome class based on the input demographic model and BSR. We then calculate the summary statsitics mentioned above, and output a csv with the true parameter values and the associated patterns of variation. 

After we construct the reference table, we create ABC-RF models for each individual parameter using the R package `abcrf`. Using the R script `ABCRF_model_create.R`, we read in the reference table then split the parameters into their own dataframes with each associated pattern of variation. For each parameter, we create a random forest regression model, sampling 200,000 replicates with replacement and growing a forest of 500 trees. After creating a model for each parameter, we save each as an RDS object, ensuring we will not need to rerun this script when estimating posterior distributions or visualizing model performance. 

Using these ABC-RF models, we estimate the posterior distribution of each parameter using `ABCRF_posterior_pred.R`. In this script, we read in the models along with the simulated data generated by `abc_dadi_combined_obs_sims.py` (which serves as the observed patterns of variation sampled from a focal population). For each simulated evolutionary replicate we obtain point estimates for each parameter based on how the observed patterns of variation fit the regression model. The posterior estiamte is summarized by the median and 95% CIs are returned by outputting the 2.5th and 97.5th quantiles. 

### Inference using dadi 

To infer the BSR and demographic history simultaneously using dadi in `Xfix_HT_dadi_optimize.py`, we start by concatenating the FS files from the autosome and the X chromsome. For this method to work, we require the sample size of the autosomes to match the X chromosome. This can be achieved even with males in the sample by projecting the autosomal SFS down to the number of X chromosomes. We simulated equal numbers of X chromosomes and autosomes, allowing us to read in the FS files from each chromosome and combine them here. After reading in the data, we use the specified `two_epoch_AX` function to fit phi and return demographic estimates and a theta value expressed in terms of the autosomes. Each simulated replicate is optimized 100 times using perturbed starting parameters to ensure the optimizer does not get caught on a local maximum. 

We extract the best-fitting parameters for each replicate using `dadi_eval_optimal_replicates.py`, where we extract the combinaton of parameters with the greatest log-likelihood and output them with the inferred theta and ll values. For the simulations with a BSR ≠ 1, we compared the log likelihood of the complex model where the BSR is inferred to a nested model where the BSR is fixed at 1 using a likelihood ratio test (LRT) in the R script `dadi_BSR_LRT.R`. This returns a p-value which we can use to reject a null hypothesis of a 1:1 BSR.


### Inference using Musharoff et al. approach 

We compared our method to a previously developed approach from Musharoff et al. ([repository linked here](https://github.com/shailamusharoff/sex-bias-inference/tree/master)). Using `Musharoff_sex_bias_inf_HT.py` we adapted the output to match that of our own dadi apporach, and input the same FS files that were simulated from `abc_dadi_combined_obs_sims.py`.
