# Breeding Sex Ratio Inference

This repository contains the scripts and packages used to infer the breeding sex ratio (BSR) and demographic history using Approximate Bayesian Computation with Random Forest (ABC-RF) and Diffusion Approximation for Demographic Inference (dadi). The `packages` directory contains conda environments with the versions of required packages used for inference and variant calling. We sort our scripts into two directories. `Method_Assessments` contains the scripts used for simulating X-linked and autosomal variation under known BSRs and demographic histories, along with a broad description of the process to infer these parameters for each method. `Maple_Ridge_Inference` contains the scripts used for applying our methods to an empircial population of _Peromyscus maniculatus_, including variant calling on the X chromosome and autosomes, filtration, and inference using both of our approaches.
