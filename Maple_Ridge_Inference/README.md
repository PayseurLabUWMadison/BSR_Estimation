## Variant Calling, Filtration, and BSR Inference for Maple Ridge Peromyscus Maniculatus

This directory contains the scripts used for variant calling, filtration, summary statistic calculation, and inference of the BSR for a population sample of deer mice collected from British Columbia (Maple Ridge). Here we will lay out the general contents of each sub-directory and highlight some of the key considerations in comparing X-linked and autosomal data 

### Variant Calling and Filtration (Var_Calling)

Our variant calling pipeline consists of two Snakemake files, `X_chr_ngs_workflow.snakefile` and `X_chr_genotyping.snakefile`, along with `Split_bam.sh` and `Call_vars_sex_sp.sh`, which are scripts designed to run in parallel through UW-Madison's Center for High Throughput Computing (CHTC). `X_chr_ngs_workflow.snakefile` presents our approach to mapping reads to the reference genome, verifying the sex of each sampled individual, and perform QC on the X chromosome and autosomes. This pipeline outputs bam files for each sample, which we then feed into CHTC to call variants in a chromosome and sex specific manner using `Call_vars_sex_sp.sh`. This script uses GATK's HaplotypeCaller to generate GVCF files for each chromosome of each sample. If creating a GVCF for an X chromosome in a male, we call genotypes as haploid; if using any other chromosome, we call genotypes as diploid. After creating GVCF's for every chromosome and sample, we pool GVCF files from each chromosome together and call variants in `X_chr_genotyping.snakefile` to return VCFs of each chromosome type and combines them into one large file. We do not need to worry about treating the X chromosome differently at this stage, as GATK's GenotypeGVCFs can handle mixed ploidy. 


Variant filtration is performed via `VCF_processing_MR.sh`, which first removes variants that fall within 10kb of any genes or lie within repeat-rich regions or previously identified large-scale inversions. Then we apply the suite of GATK hard filters to increase the confidence in called sites before also appling allele depth and max depth filters aimed at increasing the confidence in X chromosome reads. Following filtration, we filter for relatedness within the sample using `KING_relate.sh`, removing individuals such that only third-degree relatives or more distant are present within the final VCF. With this final VCF, we split the X chromosome and autosomes into non-overlapping 10kb windows for which to calculate patterns of variation using `Maple_Ridge_window_extraction.py`.

### Characterizing X-linked and Autosomal Variation (Summary_Stats)

We calculate patterns of variation among variants within the selected windows using `MR_ABC_Obs_data.R`. In this script we calculate the mean and variance of each statistic across these windows to create the input file for ABC-RF inference. Additionally we extract the minor allele frequencies to construct the folded SFS, before converting it into a FS file suited for input for dadi inference using `SFS_data_dadi.py`. We visualize the comparative patterns of variation for each of the statistics using `Vis_Summary_Stats_MR.R`

### Inference of the BSR and demographic parameters (Inference)

We input the summaries of observed variation into the ABC-RF and dadi processes described in the `Method_Assessments` sub-directory to infer the BSR along with four demographic parameters associated with a three epoch model where the population increases in size before contracting again. ABC-RF inference involves creating a reference table of 1 million simulations using `MR_abc_sims_v5.py` on CHTC. Then, we create models for each parameter using `MR_ABCRF_BSR_model_create.R` and esitmate posterior distributions with `MR_ABCRF_BSR_posterior_pred.R` with visualizations of model performance using `MR_ABCRF_OOB_plot.R`. Dadi inference optimization is performed on CHTC using `MR_HT_dadi_optimize.py`, where we perturb the starting parameters 10,000 times to find the best-fitting combination of parameters. We output the top 100 parameter combinations and perform a LRT on the model with a freely inferred BSR and a nested model where the BSR is fixed at 1:1 in  `MR_dadi_LRT.R`. We visualize the inferred parameters for each method with `MR_Plot_Inference.R`
